==============================================================================
TEXT REPRESENTATION  -  five feature sets for the classifier
==============================================================================

[1] INPUT
    train   408 sentences   {'neutral': 155, 'negative': 129, 'positive': 124}
    val      72 sentences   {'neutral': 27, 'negative': 23, 'positive': 22}
    test    120 sentences   {'neutral': 46, 'negative': 38, 'positive': 36}

    Text is already word-segmented by scripts/preprocess.py, with tokens
    joined by spaces. The vectorisers use token_pattern=\S+ because
    scikit-learn's default assumes English word characters and would drop
    Khmer script entirely.

    All five are FIT ON TRAIN ONLY and then applied to val and test.

[2] REPRESENTATIONS BUILT
    name            size             train shape
    bow             1187 features   train  (408, 1187)   sparsity 98.79%
    ngram           1565 features   train  (408, 1565)   sparsity 98.93%
    tfidf           1565 features   train  (408, 1565)   sparsity 98.93%
    word2vec         100 dims       train   (408, 100)   vocab 2883, test OOV 22.8%
    fasttext         100 dims       train   (408, 100)   vocab 2883, test OOV 22.8%

[3] WHY min_df=2
    A word appearing in only one sentence cannot generalise - it can only
    ever fire for that one example, so the model memorises instead of
    learning. On a corpus this small that matters more, not less.

[4] WHAT EACH ONE CAPTURES
    Bag-of-Words  which words appear, and how often
    N-grams       adds word pairs, so ' មិន ល្អ ' (not good) survives as one feature
    TF-IDF        down-weights words common to every sentence, lifts the
                  distinctive ones
    Word2Vec      meaning from context - words used similarly sit close
    fastText      same, plus character n-grams, so a word never seen in
                  training still gets a vector built from its pieces

    That last point is measurable here: 22.8% of the words in the test
    set never appear in training. Word2Vec drops every one of them;
    fastText builds a vector from character chunks instead.

[5] FOR PERSON 5 - loading these

    from load_features import load

    X_train, X_val, X_test, y_train, y_val, y_test = load("tfidf")

    Names: bow, ngram, tfidf, word2vec, fasttext
    Sparse ones return scipy CSR matrices, embeddings return dense numpy arrays.
    Both feed scikit-learn estimators directly, so one loop covers all five.
